# What's The Move, labor-only movers site

Marketing site for a labor-only moving company in Charleston County, SC: instant-quote flow, truck recommender, service areas, FAQ, quote form.

Stack: React 18, Vite 5, Tailwind, React Router, Framer Motion, Web3Forms for the quote form.

```bash
npm install
npm run dev     # http://localhost:5173
```

## Before launch

- Replace the placeholder phone and email in `src/data/serviceAreas.js`
- Add your Web3Forms key as `VITE_WEB3FORMS_KEY` (see `.env.example`)

`WHATS-THE-MOVE-IMPROVEMENTS-REPORT.pdf` is the improvement report from the build.

Live: https://whats-the-move-nine.vercel.app
